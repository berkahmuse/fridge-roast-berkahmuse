Entry for make.fun's "Roast the Smart Fridge: One Line, Best Laugh Wins" bounty: a program that writes one roast line of at most 160 characters — the smart fridge that caught its owner's 3am snack raid and now plays a sad trombone every time the door opens, like the owner's life choices need a soundtrack.

## Run it

```sh
python3 main.py
```

It writes the entry line to `/output/entry.txt`.
